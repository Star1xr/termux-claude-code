# termux-claude-code

Set env variable CLAUDE_SKIP_UPDATE=1 to skip the check always. (on ~/.bashrc if you want it to be perm.)

```bash
pkg install wget
wget https://raw.githubusercontent.com/Star1xr/termux-claude-code/refs/heads/main/install.sh && chmod +x install.sh && ./install.sh
```
Then run claude code with ```claude```

Checks for updates every launch.
